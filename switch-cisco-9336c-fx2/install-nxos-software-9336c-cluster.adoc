= Install or upgrade NX-OS software on Cisco Nexus 9336C-FX2 and 9336C-FX2-T cluster switches
:icons: font
:imagesdir: ../media/

[.lead]
Install or upgrade the NX-OS software on Cisco Nexus 9336C-FX2 and 9336C-FX2-T cluster switches. NX-OS must be installed before you can configure the switch or install the reference configuration file (RCF).

Before you begin, complete the procedure in link:install-nxos-overview-9336c-cluster.html[Prepare to install NX-OS and RCF].

include::../_include/install-nxos-software-9336c.adoc[]

.What's next?

After you've installed or upgraded the NX-OS software, you can link:install-upgrade-rcf-overview-cluster-9336c.html[install or upgrade the Reference Configuration File (RCF)].
