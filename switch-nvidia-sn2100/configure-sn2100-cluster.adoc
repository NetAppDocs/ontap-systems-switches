= Configure the NVIDIA SN2100 cluster switch
:icons: font
:imagesdir: ../media/

[.lead]
Configure the NVIDIA SN2100 cluster switch by following NVIDIA's documentation.

.Steps

. Review the link:configure-reqs-sn2100-cluster.html[configuration requirements].
. Follow the instructions in https://networking-docs.nvidia.com/sn2000hw/latest/system-bring-up[NVIDIA System Bring-Up.^].

.What's next?
After you've configured your switch, you can 
link:install-cumulus-mode-sn2100-cluster.html[install Cumulus Linux in Cumulus mode] or 
link:install-onie-mode-sn2100-cluster.html[install Cumulus Linux in ONIE mode].
