:icons: font

[.lead]
Cable NS224 drive shelves as switch-attached storage using NVIDIA SN2100 cluster switches when direct-attached storage is not suitable for your configuration.

https://library.netapp.com/ecm/ecm_download_file/ECMLP2876580[Cabling switch-attached NS224 drive shelves^]
