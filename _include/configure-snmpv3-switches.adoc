.About this task
The following commands are used to configure an SNMPv3 username on *Broadcom*, *Cisco*, and *NVIDIA* switches:

==== 

.Broadcom switches
--
Configure an SNMPv3 username NETWORK-OPERATOR on Broadcom BES-53248 switches.

NOTE: Beginning with ONTAP 9.20.1, you can configure SHA-512 authentication on Broadcom switches. 

* For *no authentication*:
+
[source,cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR noauth
----
* For *MD5/SHA/SHA-512 authentication*:
+
[source,cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR [auth-md5|auth-sha|auth-sha512]
----
* For *MD5/SHA/SHA-512 authentication with AES/DES encryption*:
+
[source,cli]
----
snmp-server user <snmpv3-user> NETWORK-OPERATOR [auth-md5|auth-sha|auth-sha512] [priv-aes128|priv-des]
----

The following command configures an SNMPv3 username on the ONTAP side:

[source,cli]
----
security login create -user-or-group-name <snmpv3-user> -application snmp -authentication-method usm -remote-switch-ipaddress <address>
----

The following command establishes the SNMPv3 username with CSHM:

[source,cli]
----
cluster1::*> system switch ethernet modify -device <switch-name> -snmp-version SNMPv3 -community-or-username <snmpv3-user>
----

.Example Steps
. Set up the SNMPv3 user on the switch to use SHA authentication and AES-128 encryption:
+
[subs=+quotes]
----
(sw1)(Config)# *snmp-server user SNMPv3shaAes128 NETWORK-OPERATOR auth-sha priv-aes128*

(sw1)(Config)# *show snmp user snmp SNMPv3shaAes128*

.Cisco switches
--
Configure an SNMPv3 username `<snmpv3-user>` on Cisco Nexus switches.

NOTE: Beginning with ONTAP 9.20.1, you can configure SHA-512 or SHA-256 authentication on Cisco switches.

* For *no authentication*:
+
[source,cli]
----
snmp-server user <snmpv3-user> NoAuth
----
* For *MD5/SHA/SHA-256/SHA-512 authentication*:
+
[source,cli]
----
snmp-server user <snmpv3-user> auth [md5|sha|sha-256|sha-512] <auth-password>
----
* For *MD5/SHA/SHA-256/SHA-512 authentication with AES/DES encryption*:
+
[source,cli]
----
snmp-server user <snmpv3-user> AuthEncrypt auth [md5|sha|sha-256|sha-512] <auth-password> priv [aes-128|des] <priv-password>
----

The following command configures an SNMPv3 username on the ONTAP side:

[source,cli]
----
security login create -user-or-group-name <snmpv3-user> -application snmp -authentication-method usm -remote-switch-ipaddress <address>
----

[source,cli]

.NVIDIA - CL 5.4.0
--
Configure an SNMPv3 username `<snmpv3-user>` on NVIDIA Cumulus switches running CL 5.4.0:

* For *no authentication*:
+
[source,cli]
----
nv set service snmp-server username <snmpv3-user> auth-none

+
[source,cli]

* For *MD5/SHA authentication with AES/DES encryption*:
+
[source,cli]
----
nv set service snmp-server username <snmpv3-user> [auth-md5|auth-sha] <auth-password> [encrypt-aes|encrypt-des] <priv-password>
----

The following command configures an SNMPv3 username on the ONTAP side:

[source,cli]
----
