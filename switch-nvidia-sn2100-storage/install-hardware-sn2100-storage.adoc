= Install hardware for the NVIDIA SN2100 storage switch
:icons: font
:imagesdir: ../media/

[.lead]
Install the NVIDIA SN2100 storage switch hardware by following NVIDIA's documentation. Hardware installation is the first step before configuring the switch for storage network operation.

Follow these steps to set up and configure your SN2100 switches. Refer to NVIDIA's documentation for detailed instructions.

.Steps

. Review the link:configure-reqs-sn2100-storage.html[configuration requirements].
. Follow the instructions in the link:https://networking-docs.nvidia.com/sn2000hw/latest/installation[NVIDIA Switch Installation Guide^].

.What's next?

After you've installed your hardware, you can link:cabling-considerations-sn2100-storage.html[review cabling and configuration] requirements.
