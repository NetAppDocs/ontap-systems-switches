= Install the RCF script on NVIDIA SN2100 storage switches
:icons: font
:imagesdir: ../media/

[.lead]
Install the reference configuration file (RCF) script on NVIDIA SN2100 storage switches to configure port assignments and network settings.

.Before you begin
Before installing the RCF script, make sure that the following are available on the switch:

* Supported version of Cumulus Linux is installed.
* Management port IP address, subnet mask, and default gateway defined via DHCP or manually configured.

.RCF script version
Select the appropriate storage RCF script version based on your current ONTAP and Cumulus Linux version. Download RCFs from https://mysupport.netapp.com/site/info/nvidia-cluster-switch[NVIDIA SN2100 software download^] page.

.About the examples

The following example procedure shows how to download and apply the RCF script for Storage switches.

. Copy the RCF python script to the switch:
+
[subs=+quotes]
----
admin@sw1:mgmt:~$ *pwd*
/home/cumulus
cumulus@cumulus:mgmt:~$ *cd /tmp*
cumulus@cumulus:mgmt:/tmp$ *scp <user>@<host:/<path>/RCF-v1.14-MSN2100-ST1*
ssologin@10.233.204.71's password:
RCF-v1.14-MSN2100-ST1                 100% 8607   111.2KB/s         00:00
----
. Apply the RCF python script *RCF-v1.14-MSN2100-ST1*:
+
[subs=+quotes]
----
cumulus@cumulus:mgmt:/tmp$ *RCF-v1.14-MSN2100-ST1*
[sudo] password for cumulus:
...
Step 1: Creating the banner file
Step 2: Registering banner message
Step 3: Updating the MOTD file
Step 4: Ensuring passwordless use of cl-support command by admin
Step 5: Disabling apt-get
Step 6: Creating the interfaces
Step 7: Adding the interface config
Step 8: Disabling cdp
Step 9: Adding the lldp config
Step 10: Adding the RoCE base config
Step 11: Modifying RoCE Config
Step 12: Configure SNMP
Step 13: Reboot the switch
----
+
The RCF script completes the steps listed above.
+
NOTE: For any RCF python script issues that cannot be corrected, contact https://mysupport.netapp.com/[NetApp Support^] for assistance.

. Reapply any previous customizations to the switch configuration. Refer to link:cabling-considerations-sn2100-storage.html[Review cabling and configuration considerations] for details of any further changes required.

. Connect the controller storage ports and NS224 shelf ports to the switches.
