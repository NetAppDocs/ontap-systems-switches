= Migrate to a two-node switched cluster using Cisco Nexus 9336C-FX2 storage switches
:icons: font
:imagesdir: ../media/

[.lead]
Migrate an existing two-node switchless cluster to a switched cluster environment using Cisco Nexus 9336C-FX2 and 9336C-FX2-T storage switches. This nondisruptive migration enables you to scale the cluster beyond two nodes.

The migration process works for all nodes using optical or Twinax ports, but is not supported on this switch if nodes are using onboard 10Gb BASE-T RJ45 ports for the cluster-network ports.
